Setup guide (2 minutes)
Deriv launched a new API in 2026. The old numeric app_id (like 1089) and the old API tokens from app.deriv.com no longer work — the alphanumeric App ID is the right one.
  1. Open developers.deriv.com/dashboard and log in with your normal Deriv login.
  2. Register application → type PAT (not OAuth) → any name → save. Copy the App ID.
  3. API tokens → Create token → tick scope trade → copy the token immediately (shown once).
  4. Paste both above → Connect account. Your accounts appear in the dropdown — pick DEMO to test.
No domain, hosting or payment is needed — this page talks to Deriv directly from your device.
Opening the app & keeping it secure
Opening it — tap ▶ Run in Acode (Chrome opens a localhost address that exists only inside your phone), open the file from your Files app with Chrome, or publish it free on GitHub Pages for an https link (see SETUP.md). There is no server of ours — only this page talking to Deriv.
  • Token scope = trade only. Never payments or admin: even a leaked token cannot withdraw or change your account.
  • PIN lock. The token is stored encrypted (AES-256-GCM, key from your PIN via PBKDF2). Tap Lock when you put the phone down; it also locks after 10 minutes without touch (never during a session or with open trades).
  • Content Security Policy. The page may only talk to api.derivws.com and loads nothing from anywhere else — no libraries, fonts or trackers.
  • Phone lost or token seen? developers.deriv.com → API tokens → delete it and create a new one. Review sessions at app.deriv.com → Settings → Security.
  • Real money. The app asks for confirmation before the first trade on a REAL account. Stay on DEMO until you are sure.
Use on another device
Create a transfer code: it carries your token and App ID encrypted with your password (8+ characters). On the other device open the app — the same hosted link, or the same index.html — import it once, and from then on that device asks only for your password.

Advanced settings
Gap = top digit % minus the runner-up digit % (any digit 0–9). Ties are broken by streak length, then top-digit %.
Scanner rules
streak length, both sides
last N digits > it and top digit ≤ it → Over
last N digits < it and top digit ≥ it → Under
How the scanner decides
Two signals, scanned at the same time. Over 3: the latest 8 digits are all > 3 and the most frequent digit over the last 1000 ticks is 0–3 → trades Digit Over 3. Under 6: the latest 8 digits are all < 6 and the most frequent digit is 6–9 → trades Digit Under 6. Whichever appears first is executed. If several markets qualify at the same time, the one whose top digit leads its runner-up digit by the biggest gap wins — e.g. top digit 2 at 12.2% and 2nd digit 5 at 10.9% is a gap of 1.3 points; a market with a gap of 2.0 is preferred. The runner-up can be any digit 0–9. Equal gaps are broken by the longer streak, then the higher top-digit %. (Advanced settings can switch this to "longest streak first".)

Sessions. Each signal starts one session: the best qualifying market gets exactly Bulk trades contracts, sent all at once or one after another (next one after the previous result). The scanner then waits for the next signal and repeats until Max sessions is reached, then stops by itself. A market must break its streak and form a fresh one before the same side is traded on it again. Take profit, stop loss and Stop end everything early.
